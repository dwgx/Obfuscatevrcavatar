Primary sources, not blogs.

## AvatarObfuscator (cocokoishi) v0.4.9

- Release unitypackage: `https://github.com/cocokoishi/AvatarObfuscator/releases/download/v0.4.9/dev.cocokoishi.avatar-obfuscator-0.4.9.unitypackage`
- README: NDMF ≥ 1.6, Unity 2022.3, clone-only homoglyph names (ÌÍÎÏ).
- Obfuscates: blendshapes, GameObject names, animator params + VRC params, cloned mat/tex/audio names.
- Does not: shaders, reserved VRC params, head mesh if Preserve MMD.
- Texture path: **use TexTransTool**, they removed their own.
- Reproducible seed default `5145514`.
- Tip: MA Manual Bake first if errors.

## Kanna Protecc / PlagueVRC AntiRip

- https://github.com/PlagueVRC/AntiRip
- Vertex scramble on Basis + custom shader + **32 synced bits**.
- Supported shaders: Poiyomi, UTS, Sunao, XSToon, GTAvaToon. **Not lilToon.**
- Invisible if viewer disables shaders (hedgehog / fallback).
- Write Keys into LocalAvatarData. Delete old unencrypted uploads.
- Not immune to specialized hotswap (their own README).

## VPM listing (private GitHub)

- Official listing: https://vcc.docs.vrchat.com/guides/create-listing/ — GitHub Pages `index.json`, public HTTPS by default.
- Add to VCC: https://vcc.docs.vrchat.com/guides/community-repositories/ — 2.1+ Settings → Packages → Add Repository; cogwheel headers for private listing JSON (`Authorization: Bearer`).
- Local listing: `vpm add repo <path>` accepts a local json file (https://vcc.docs.vrchat.com/vpm/cli/).
- Private GitHub **as VPM zip host**: VCC issue 455 — listing header ≠ private Release asset download; PAT in VCC settings is a leak surface. Source-private + local VCC/UPM is the Owner path.
