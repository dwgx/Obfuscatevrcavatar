## What “author-PC fingerprint HTTP” means

Three hops. Only hop 1 exists today.

1. **Localhost (author Unity / `preview.ps1`).** Browser on the **author’s PC**
   talks to `http://127.0.0.1:17849/`. Computes `ova-fp-v1` = SHA-256 of
   seed + nameLength + watermark on/off + amplitude. Stores PAT in
   `Library/OVA/secrets.json` (gitignored with `Library/`). Never returns the PAT.
2. **Outbound HTTPS (not wired).** Same PC would `PUT` GitHub Contents (or
   Gitee create/update) a **public JSON** `{ algo, fingerprint }`. PAT is an
   Authorization header (GitHub) or `access_token` (Gitee). Not a decrypt key.
3. **Humans later.** If a reupload shows up, you compare that public hex to
   your bake settings (or to a private log). **VRChat viewers never hit this.**
   The uploaded avatar has no author C# and cannot call GitHub.

It is **not**: OSC password, menu roulette, in-world challenge, mesh ciphertext,
or a viewer-side “verify then draw”. Synced params are a public draw channel.
Fingerprint is **settings identity**, not a mesh content hash — two avatars
with the same seed/length/watermark collide.
