# OVA — Obfuscate VRChat Avatar

Chinese is the default: [README.md](README.md). Japanese later.

Blue-team avatar protection for **your own** Unity 2022.3 VRChat avatars. NDMF runs on the upload clone. Not a ripper. Ripping is never 100% solvable; private instances are the only near-guarantee.

VPM package id: `dev.ova.protection` **0.3.0-pre.1** ([github.com/dwgx/Obfuscatevrcavatar](https://github.com/dwgx/Obfuscatevrcavatar)). Clone-only names, parameters (with GoGo/FT preserve), cloned asset names, tiny watermark. Control plane: **ova-web** (Material 3) on localhost. GitHub/Gitee attest is fingerprint-only; publish is not wired. Human SDK upload is still open. See [docs/PLAIN.md](docs/PLAIN.md), [docs/WORKFLOW.md](docs/WORKFLOW.md), [docs/VCC.md](docs/VCC.md).
